# КАРТОЧКА ПРОЕКТА

## **1. Разработка веб-сервиса аналитики Spotify «sleepwalker.fm»

### **1.1 Карточка/Паспорт проекта**

#### **1.1.1 Название проекта**

Разработка веб-сервиса для углубленной аналитики Spotify с интеграцией Last.fm, персонализированными рекомендациями и Wrapped-режимом «sleepwalker.fm»

#### **1.1.2 Цель проекта**

Разработать и запустить веб-сервис, который позволит пользователям Spotify получать детальную статистику своего прослушивания музыки в любой момент времени (не ограничиваясь встроенным Spotify Wrapped один раз в год), получать персонализированные рекомендации на основе музыкального профиля, анализировать жанровые предпочтения посредством Last.fm API и экспортировать рекомендации в виде плейлистов.

#### **1.1.3 Критерии успеха**

**1.1.3.1 Аутентификация:** Надежная интеграция с API Spotify OAuth 2.0 с использованием PKCE для безопасности

**1.1.3.2 Фильтрация:** Возможность выбора произвольного временного периода (неделя, месяц, год, все время)

**1.1.3.3 Функциональность:** Отображение статистики (топ-50 треков, топ-50 артистов, недавно слушанное, жанры, аудиохарактеристики)

**1.1.3.4 Рекомендации:** Генерация персонализированных рекомендаций с двумя режимами (comfort, explore)

**1.1.3.5 Доступность:** Доступен для всех пользователей Spotify независимо от типа подписки

**1.1.3.6 Производительность:** Быстрая загрузка данных (<5 сек) благодаря кэшированию и оптимизации

**1.1.3.7 UX:** Интуитивный интерфейс с полной локализацией и поддержкой темной темы

## **2. Содержание проекта**

sleepwalker.fm — это веб-сервис, который предоставляет пользователям детальную аналитику их активности на Spotify в любой момент времени. В отличие от встроенной статистики Spotify (доступна только один раз в год и не на всех тарифах) и платных сервисов (с рекламой и ограничениями), sleepwalker.fm предлагает полную гибкость: выбирайте любой период времени, получайте обширную информацию о музыкальных предпочтениях, анализируйте жанры через Last.fm API и получайте персонализированные рекомендации.

### **2.1 Функционал**

**2.1.1** Авторизация через Spotify OAuth 2.0 с PKCE flow

**2.1.2** Просмотр статистики прослушиваний за выбранный период

**2.1.3** Топ-50 треков с метриками (популярность, длительность, артисты, альбомы)

**2.1.4** Топ-50 исполнителей с популярностью, жанрами и фото

**2.1.5** Фильтрация по временным периодам (short_term, medium_term, long_term)

**2.1.6** Аудиохарактеристики (дanceability, energy, valence, tempo, acousticness и т.д.)

**2.1.7** Определение жанров на основе Last.fm API

**2.1.8** Персонализированные рекомендации (режимы: comfort, explore)

**2.1.9** Экспорт рекомендаций в виде плейлиста в Spotify

**2.1.10** Wrapped-режим с insights, timeline и сравнением периодов

**2.1.11** Кэширование данных (Redis) для быстрого доступа

**2.1.12** Дедупликация одновременных запросов (singleflight)

#### **2.1.13 Рекомендации на основе прослушиваний: детальное описание**

**Возможность реализации:** ДА (полностью реализовано)

**Методы:**

**2.1.13.1** Использование встроенного Spotify Recommendations API — метод 1. Spotify предоставляет API эндпоинт `/v1/recommendations`, который принимает seed_artists, seed_tracks, seed_genres и возвращает релевантные треки. Это основной способ (быстро, надежно).

**2.1.13.2** Обогащение Last.fm жанрами — метод 2. Для каждого топ-артиста пользователя запрашиваются top tags из Last.fm, которые нормализуются и взвешиваются. Это обеспечивает более точные рекомендации.

**2.1.13.3** Анализ audio_features — метод 3. Парсятся параметры топ-треков пользователя (энергия, танцевальность, валентность и т.д.) для построения музыкального профиля.

**2.1.13.4** Гибридный подход — комбинация всех методов. Last.fm жанры + Spotify Recommendations API + audio_features анализ для лучшего результата.

**Трудность:** Средняя (реализовано). Требует дополнительного кэширования и построения логики матчинга. Текущая реализация использует Last.fm для жанров, Spotify API для семян и фильтрации.

### **2.2 Выгоды от реализации**

#### **2.2.1 Для пользователей**

Пользователи получают инструмент для анализа своего музыкального вкуса в любой момент времени (не один раз в год), без рекламы и ограничений, доступный для всех подписчиков Spotify. Можно отслеживать как менялись предпочтения с течением времени, получать новые рекомендации и делиться плейлистами.

#### **2.2.2 Для создателей проекта**

Портфолио-проект, демонстрирующий навыки в области:
- Интеграции с внешними API (Spotify Web API, Last.fm API)
- Full-stack разработке (Go Backend + Next.js Frontend)
- Аутентификации и работе с OAuth 2.0
- Оптимизации производительности и кэшированию
- Work with databases (PostgreSQL, Redis)
- DevOps навыки (Docker, Docker Compose)
