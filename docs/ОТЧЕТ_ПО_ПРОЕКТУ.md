# ОТЧЕТ ПО ПРОЕКТУ — sleepwalker.fm

## **1. Краткое описание**

sleepwalker.fm — учебный проект (курсовая работа). Веб-сервис предоставляет пользователям расширенную аналитику их активности в Spotify с возможностью анализа за произвольный период времени, персонализированные рекомендации на основе музыкального профиля с обогащением данными из Last.fm, а также режим Wrapped с детальными insights и сравнением временных периодов.

## **2. Цели и задачи**

**2.1** Реализовать авторизацию через Spotify OAuth 2.0 с использованием PKCE для безопасности

**2.2** Собирать и кэшировать данные о прослушиваниях пользователя (топ-артисты, топ-треки, history)

**2.3** Показывать статистику за выбранный период (неделя, месяц, год, все время)

**2.4** Интегрировать Last.fm API для определения жанров пользователей

**2.5** Реализовать рекомендационный движок с двумя режимами (comfort, explore)

**2.6** Добавить функцию экспорта плейлиста в Spotify

**2.7** Создать Wrapped-режим с insights, timeline и сравнением периодов

**2.8** Оптимизировать запросы через Redis кэширование и singleflight дедупликацию

## **4. Реализованный функционал**

### **4.1 Авторизация и Session Management**

- OAuth 2.0 с PKCE flow (code_verifier + code_challenge)
- Secure token storage (refresh tokens только на backend)
- Token refresh mechanism ahead of expiration (RefreshBuffer = 5 min)
- Session endpoints для фронтенда

### **4.2 Spotify Data Pipeline**

- Fetch top artists (50 за период)
- Fetch top tracks (50 за период)
- Fetch recently played (история прослушивания)
- Fetch audio features (дanceability, energy, valence, tempo и т.д.)
- Snapshot кэширование на 30 мин

### **4.3 Last.fm Интеграция**

- Artist top tags fetching
- Concurrent genre aggregation (семафор = 4 одновременных запроса)
- Tag normalization (hip-hop → hip hop, r&b → rnb)
- Fallback на Spotify artist.genres если Last.fm недоступен

### **4.4 Рекомендационный Движок**

- Mode comfort: знакомая музыка на основе top artists/tracks/genres
- Mode explore: новые исполнители в похожих жанрах
- Seed selection (5 artists + 5 tracks + 5 genres max)
- Playlist export с бэкофф при ошибках

### **4.5 Wrapped Функционал**

- Summary: числовая статистика (avg popularity, danceability, listening time)
- Insights: текстовые insights (highlights, tags, listener profile)
- Timeline: тренды по часам и дням
- Compare: сравнение двух периодов (track overlap, artist overlap, новые треки)

### **4.6 Performance & Optimization**

- Redis кэш для snapshots (TTL 30 min)
- Singleflight дедупликация одновременных запросов
- Rate limiting aware logic (Spotify: 6 req/sec global, 1 req/sec per user)
- Stale cache fallback при rate limiting
- Batch API calls (audio features, playlist add)

### **4.7 Frontend**

- Landing page с кнопкой "Connect Spotify"
- Protected pages (Dashboard, Recommendations, Wrapped, Playlist)
- Auth guard для защиты маршрутов
- Полная локализация (i18next)
- Темная тема (Tailwind + Radix UI)
- Token refresh в фоне
