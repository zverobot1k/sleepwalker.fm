# УСТАВ ПРОЕКТА — sleepwalker.fm

## **1. Общая информация**

**Название проекта:** sleepwalker.fm — веб-сервис аналитики Spotify с интеграцией Last.fm (курсовая работа).

**Исполнитель:** Максим Блохин (студент).

**Статус:** В разработке. Проект является курсовой работой и включает полный функционал аналитики, рекомендаций и Wrapped-режима на финальном этапе.

## **2. Цель проекта**

Создать веб-сервис, позволяющий пользователям Spotify просматривать детальную статистику прослушиваний в любой момент времени (не только один раз в год как Spotify Wrapped), получать персонализированные рекомендации на основе музыкального профиля с обогащением данных через Last.fm, анализировать жанровые предпочтения и тренды прослушивания.

## **3. Объем работ (Scope)**

**3.1** Интеграция с Spotify API и авторизация через OAuth 2.0 с PKCE

**3.2** Интеграция с Last.fm API для обогащения жанровыми данными

**3.3** Сбор и кэширование статистики пользователя (топ-артисты, топ-треки, recently played)

**3.4** Отображение статистики за выбранный период (short_term, medium_term, long_term)

**3.5** Рекомендационный движок на основе музыкального профиля

**3.6** Playlist export в Spotify

**3.7** Wrapped-режим с insights, timeline и сравнением периодов

**3.8** Оптимизация запросов через кэширование (Redis) и dедупликацию (singleflight)

**3.9** Frontend на Next.js 15 с React 18 и полной локализацией

## **4. Ограничения и допущения**

**4.1** Проект выполняется одним студентом как курсовая работа — сроки фиксированы.

**4.2** Данные берутся из Spotify Web API (основной источник) и Last.fm API (для жанров).

**4.3** Refresh tokens хранятся только на backend и никогда не передаются на frontend.

**4.4** Rate limiting Spotify API (6 req/sec глобально, 1 req/sec per user) обрабатывается через stale cache fallback.

**4.5** Last.fm может быть недоступен — предусмотрен fallback на Spotify artist.genres.
